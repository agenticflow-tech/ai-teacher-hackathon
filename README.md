# 🎓 AI Teacher: Adaptive Virtual Educator

An intelligent, adaptive educational assistant powered by the Google Gemini API and Streamlit. This application transforms topics or uploaded study documents into personalized, human-like lesson plans and features an interactive quiz system that detects and corrects student misconceptions in real time.

---

## ✨ Key Features
* **Customized Lesson Generation:** Produces dynamic learning sessions tailored to chosen education levels, languages, and available time slots.
* **Interactive Misconception Engine:** Evaluates student answers, identifies conceptual errors gently, and re-explains topics using fresh real-world analogies.
* **Document Processing:** Supports uploading PDF, DOCX, and TXT files to turn custom study materials directly into interactive lessons.

---

## 🛠️ Tech Stack
* **Frontend & Web UI:** Streamlit
* **AI Engine:** Google Gemini API (`gemini-3.6-flash`)
* **Core Language:** Python 3.14
